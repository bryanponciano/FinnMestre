## 📌 About the Project
FinnMestre is a comprehensive full-stack financial management system designed to help users track income, expenses, accounts, and financial goals. It provides a clear overview of financial health and simplifies money management through an intuitive interface. 

## 🚀 Key Features
- **Cash Flow Tracking:** Monitor daily income and expenses with detailed categorizations.
- **Financial Goals:** Set, track, and manage progress for long-term financial objectives.
- **Admin & Sales Dashboard:** Integrated sales page with full administration panel control.
- **WhatsApp Bot Integration:** Includes automated scripts for WhatsApp notifications and interactions.
- **Data Integrity:** Secure relational database structuring to ensure financial data reliability.

## 🛠️ Technologies Used
- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript
- **Automation:** Python, PowerShell & Batch scripts
